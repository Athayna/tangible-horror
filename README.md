# HSRM Passive Haptics

A VR project exploring passive haptics, built with Unity and the Meta XR SDK at Hochschule RheinMain.

## Requirements

- Unity 6000.3.16f1
- Meta Quest headset (uses Meta XR SDK / OpenXR)

## Third-party assets

Third-party assets live under `Assets/ThirdPartyAssets/` and are excluded from this repository (see `.gitignore`) because their licenses do not permit redistribution.

To run the project locally, re-acquire the following packs and place each one in `Assets/ThirdPartyAssets/` under the folder name given below (keep the original `.meta` files from the packs so asset references resolve):

| Folder | Asset pack | Source |
|---|---|---|
| `Altar_Ruins_FREE` | Altar Ruins FREE | _link TBD_ |
| `Bowl` | Bowl | _link TBD_ |
| `Cabin` | Cabin | _link TBD_ |
| `EYE ADVANCED` | EYE Advanced (Tanuki Digital) | _link TBD_ |
| `MeasureMaster` | MeasureMaster (Measurements Tool for Unity) | _link TBD_ |
| `WoodBucket` | Wood Bucket | _link TBD_ |
| `Worms FREE` | Worms FREE | _link TBD_ |

The folder `Assets/_TerrainAutoUpgrade/` is auto-generated by Unity when it upgrades the terrains contained in these packs and is also excluded from the repository.
