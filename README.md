# Tangible Horror – Tangible VR Illusions

A VR research prototype exploring passive haptics and horror, built in Unity for the Master Project in Media Computer Science (Intelligent and Interactive Systems) at Hochschule RheinMain, Summer Semester 2026.

Created by Alexandra Müller and Leonie Ferdinand, supervised by Prof. Dr. Jörg Berdux. The project is [officially announced on the HSRM website](https://www.hs-rm.de/design-informatik-medien/design-informatik-medien-in-wiesbaden/informatik-in-wiesbaden/master-projekte/projekt-1-1-1-4-4).

## About

Modern VR headsets deliver high-fidelity visuals and audio, but touching a virtual object and feeling nothing but empty air quickly breaks immersion. Active haptic hardware is complex, expensive, and restrictive — so this project explores **passive haptics** and **visuo-haptic illusions** instead: inert, real-world objects act as physical proxies for their virtual counterparts, letting players physically touch what they visually perceive.

The research focuses on horror: a sense of dread, understood as a derived emotion composed of disgust and fear. The prototype deliberately pairs virtual scenes with physical textures and objects designed to trigger these negative emotional responses. The core questions: does haptic feedback measurably amplify disgust and dread in VR, and does touching real proxy objects make the virtual illusion more psychologically immersive?

## The prototype

A modular VR prototype for Meta Quest with multiple experimental setups that pair everyday physical objects with distinct virtual experiences — for example, a bucket of worms or a bowl of eyes whose virtual size is calibrated to match a real object the player can reach out and touch.

The prototype supports user tests comparing the passive haptics condition against a standard baseline. Evaluation uses standardized HCI metrics — the Igroup Presence Questionnaire (IPQ) for presence and the Self-Assessment Manikin (SAM) for emotional arousal and valence — plus physiological data such as heart rate variability (HRV).

## Tech stack

- Unity 6000.3.16f1
- Meta XR SDK (via Unity Package Manager) / OpenXR, targeting Meta Quest
- C#, Universal Render Pipeline (URP)

### Project structure

```
Assets/
  Scenes/            main study scene and testing playgrounds
  Scripts/           gameplay and study logic
  Prefabs/           proxy object prefabs (bucket with worms, bowl with eyes, camera rig)
  ThirdPartyAssets/  third-party models and tools (not in this repo, see below)
  ...
_docu/
  expose/            project exposé (LaTeX + PDF)
```

Core scripts:

- `GameManager` drives the study flow with and between the haptic conditions.
- `SetRealWorldSize` scales virtual objects to match their real-world proxy dimensions.
- `WorldLockAnchor` keeps virtual objects locked to their physical counterparts' positions.
- `WormManager` / `EyeManager` control the animated contents of the proxy objects.
- `AuthoringManager` supports setting up and aligning the experimental scenes.
